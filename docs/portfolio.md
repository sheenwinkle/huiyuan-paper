# 作品集包装

## 项目一句话

为中国长三角纸制祭祀用品加工厂构建的 AI 驱动数字化官网与客户管理系统。

## 面试讲法

这个项目从真实家庭工厂业务出发，不是单纯做一个页面，而是把传统销售流程拆成软件系统：

1. 官网展示工厂可信度和主营产品。
2. AI 客服先承接客户问题，避免人工重复回答。
3. 询盘进入后台，销售人员继续跟进。
4. 产品资料和客服知识库可以持续维护。
5. 系统可以从小微企业官网演进为行业 SaaS。

## 技术亮点

- Next.js App Router 实现官网、后台和 API。
- Prisma 建模产品、询盘、聊天、知识库和管理员。
- 后台使用 HttpOnly Cookie 做基础登录保护。
- AI 客服通过 Provider 抽象，默认规则回复，后续可接模型。
- Docker Compose 支持真实业务部署。
- Cloudflare Pages 支持免费作品集演示。
