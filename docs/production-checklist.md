# 真实上线检查清单

## 账号与安全

- 更换 `ADMIN_PASSWORD`
- 生成强随机 `AUTH_SECRET`
- 设置服务器防火墙
- 后台路径和登录失败限制
- 定期更新依赖

## 数据库

- PostgreSQL 使用强密码
- 开启定期备份
- 确认备份可恢复
- 不在代码仓库提交 `.env`

## 业务资料

- 工厂门头照片
- 生产设备照片
- 产品实拍
- 产品图片外链或对象存储地址
- 包装和发货照片
- 微信二维码
- 联系电话
- 真实地址
- 产品规格资料

## AI 客服边界

- 不自动报价
- 不承诺库存
- 不承诺账期
- 不承诺发货时效
- 专业问题转人工
- 客户联系方式进入后台

## 运营后台

- 给产品补充真实图片链接
- 给产品补充常见规格和包装说明
- 每天查看高优先级询盘
- 维护下次跟进日期
- 定期导出 CSV 备份客户线索

## 中国大陆上线

- 购买域名
- 完成实名认证
- 如果使用大陆服务器，完成ICP备案
- 如果涉及经营性互联网服务，进一步确认相关要求

## 可暂时绕开的事项

- 文件上传：第一版使用图片链接，后续再接阿里云 OSS。
- 1688 联动：第一版使用 1688 店铺链接、二维码或客服引导，等账号和接口能力确认后再做自动同步。
- 真实 AI API：第一版使用规则客服和知识库，等真实咨询量上来后再接 OpenAI、Gemini 或国产模型。
